# C03 Source Register

## Purpose

This directory is the source/provenance index for the C03 Real Estate engineering track. It is not a second canonical authority and must not duplicate decision artifacts.

## Authority rule

One concept has one canonical owner. Source material is evidence for reconciliation; the canonical decision remains in the C03 engineering track and the project-wide governance registers.

## Current source classes

- Real Estate domain/resource-model research
- Project / Building / Floor / Unit research and contracts
- Listing / mandate research
- Reservation and concurrency research
- Persistence / brownfield reconciliation records
- C03 conference checkpoints and closure reviews
- Cross-domain C03–C06 research where C03 is materially affected
- Historical C03 decisions and amendments

## Required classification

Every source artifact must eventually be classified as exactly one primary status:

- `CANONICAL-SOURCE`
- `SUPPORTING-EVIDENCE`
- `CROSS-DOMAIN-SOURCE`
- `HISTORICAL-SOURCE`
- `SUPERSEDED-SOURCE`
- `CONFLICTING-SOURCE`
- `UNVERIFIED-SOURCE`

## Reconciliation rule

Do not close C03 because a source exists. Each material source must be reconciled against the current V3 architecture, contracts, registers, repository reality, runtime reality, and higher-authority decisions where applicable.

## Closure dependency

C03 remains OPEN until the material source set has been reconciled and the independent closure review has no unresolved blocking contradiction.
