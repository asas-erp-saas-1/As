## Changes

1. Architecture decisions must use external engineering research when ASAS sources do not adequately answer a material engineering question.
2. External research validates engineering technique but never overrides founder/product authority, approved ASAS architecture, contracts, registers, or verified runtime reality.
3. Context/module decomposition is evidence-driven; counts are never architecture objectives.
4. Operational excellence, reliability, security, observability, reversible change and failure rehearsal are architecture concerns, not post-production extras.
5. Codex is operated through focused, task-relevant skills and canonical routing rather than indiscriminate full-repository context loading.
6. Architecture-changing tasks require broader provenance discovery than routine implementation tasks.

## Architectural status

No product scope, bounded-context ownership, persistence model, or runtime fact is promoted by this amendment. Existing open/conflict/blocked states remain unchanged unless separately closed with evidence.
