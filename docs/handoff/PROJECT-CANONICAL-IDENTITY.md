## Absolute identity rule

`asas-erp-saas-1/As` is the sole canonical GitHub repository for the ASAS Real Estate Operating System in this engineering program.

All architecture, product decisions, implementation planning, engineering contracts, task orchestration, verification records, and future application code belong to this repository unless a future decision explicitly creates a dedicated repository boundary.

## What this repository is

ASAS is being engineered as an integrated Real Estate Operating System covering:

- Public real-estate website and publishing Studio
- Projects, buildings, inventory and units
- CRM and sales lifecycle
- Leads, activities, appointments and communications
- Reservations, options, contracts and payment schedules
- Finance and accounting controls
- Marketing, attribution and analytics
- Developer/promoter workspaces and property stock management
- HR/People capabilities
- Administration, permissions and governance
- External integrations and provider adapters
- AI-assisted operational and executive workflows
- Future multi-company, multi-workspace and SaaS expansion

## Repository boundaries

The repository is currently in foundation/planning mode. Do not introduce application code, database schema, migrations, infrastructure resources, or production mutations until the corresponding readiness gate is explicitly green.

The repository is the canonical destination for the validated engineering contract. External source packages and research material are inputs to be validated and distilled; they are not automatically copied wholesale into the repository.

## Authority model

Use this order when determining what ASAS means:

1. Explicit founder-confirmed product decisions recorded in the canonical state.
2. Canonical ASAS architecture and machine-readable contracts.
3. Approved task packets and acceptance criteria.
4. Validated research and standards evidence.
5. Historical material only when explicitly promoted.

If two authoritative artifacts conflict, stop and record the contradiction. Never silently choose one.
