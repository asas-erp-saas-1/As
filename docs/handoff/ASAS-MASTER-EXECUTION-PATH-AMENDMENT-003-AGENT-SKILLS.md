# ASAS — MASTER EXECUTION PATH AMENDMENT 003 — AGENT SKILLS

**Status:** CANONICAL AMENDMENT  
**Effective date:** 2026-09-23

## Execution addition

The execution path now includes a capability-selection gate immediately before authorized implementation:

```text
Task Packet
→ Authority Check
→ Skill Selection
→ Local/Tool Readiness
→ Codex Implementation
→ Independent Verification
```

## Skill selection

Codex must select the smallest sufficient set from:

- repository forensics;
- architecture governance;
- domain contracts;
- database engineering;
- security/AI safety;
- design fidelity;
- testing/verification;
- observability/reliability;
- master ASAS engineering.

## Figma path

For UI work:

`Accepted design contract → Figma MCP/Code Connect context when available → Codex implementation → browser render → visual/accessibility/responsive verification → evidence`.

A Figma frame alone never authorizes a business-domain change.

## Database path

For schema work:

`Closed domain contract → schema contract → local DB → migration → replay → constraints/RLS/concurrency tests → evidence → controlled integration`.

## Research path

For gaps:

`repository → branches/history → source package → official research → corroboration → engineering derivation → contract/ADR → task authorization`.

## Hard stop

No skill can bypass a blocked gate or founder decision.
